# `plans/assets` — UI/UX Design References

## Overview

The `plans/assets` directory stores visual artifacts, color palette definitions, and interface design references that establish the aesthetic identity of Scrape: a high-contrast, brutalist interface inspired by NieR:Automata.

---

## File Manifest

| File | Design Concept | Description |
|---|---|---|
| [`ref-nier-menu.png`](ref-nier-menu.png) | Menu & Interface Hierarchy | Visual reference capturing the 0px border radius, monospaced data grids, uppercase hierarchy, and high-contrast lines of the NieR:Automata UI. |
| [`ref-palette.png`](ref-palette.png) | Color System & Contrast | Palette specifications establishing the primary base colors (Paper `#F5F5DC`, Cream `#FFF6EE`, Ink `#1A1A1A`, Obsidian `#262628`) and restrained stage/signal accents (lavender `#C6C2F2`, lime `#D6DC82`, cherry `#D86072`, signal `#1F1FE0`). |
| [`ref-dither.png`](ref-dither.png) | Dithering Patterns | Reference patterns used to implement sparse brutalist CSS dither effects (`.bg-dither`) for decorative accents and drop zones. |
| `08-desktop-review/`, `10-ui-review/`, `11-keyword-review/`, `11-enrichment-review/`, `11-branding-review/` | Implementation Review Captures | Visually inspected Paper and Obsidian screenshots recorded as verification evidence for each plan section. |
