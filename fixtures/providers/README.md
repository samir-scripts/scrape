# Provider fixtures

`manifest.json` identifies raw, timestamped public provider captures by their capture URL and SHA-256. Files under `regressions/` may instead be authored deterministic edge cases. Each authored case must declare `fixture_kind`, keep `source_capture` null, and must never be described or tested as a live provider response.

`regressions/remote-us-availability-authored.json` is an authored Greenhouse-shaped case paired with a negative company-prose control. `regressions/cloudflare-8024849.json` is a minimal projection of the official Cloudflare Greenhouse API response captured on 2026-10-15. Its SHA-256 is recorded in the fixture; the complete 18,972-byte response was retained locally at `/private/tmp/cloudflare-job-8024849.json` for this verification but is not copied into the repository. The captured posting ID, title, `absolute_url`, Remote label, `first_published`, update timestamp, and labeled “Available Locations: US” excerpt match the supplied screenshot. The worker/repository regression uses the captured posting plus the authored negative control.
