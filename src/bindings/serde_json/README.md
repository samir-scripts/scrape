# `src/bindings/serde_json` — Serde JSON Type Bindings

## Overview

The `src/bindings/serde_json` directory contains TypeScript bindings generated by `ts-rs` for `serde_json::Value`.

---

## File Manifest

| File | Type Definition | Description |
|---|---|---|
| [`JsonValue.ts`](JsonValue.ts) | `JsonValue` | Recursive TypeScript type definition representing any valid JSON value (`string`, `number`, `boolean`, `null`, `object`, or `array`), mapping to `serde_json::Value` in Rust data models. |
