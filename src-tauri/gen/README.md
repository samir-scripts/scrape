# `src-tauri/gen` — Generated Build Artifacts & Schemas

## Overview

The `src-tauri/gen` directory is generated and maintained by the Tauri CLI during compilation and configuration validation. It contains JSON schema definitions used by IDEs and tooling to validate Tauri v2 configuration files and Access Control Lists (ACL).

---

## Subdirectories

| Directory | Description |
|---|---|
| [`schemas/`](schemas/README.md) | JSON schemas describing capabilities, desktop configuration options, and platform-specific bundle settings. |
