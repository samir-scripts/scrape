# `src-tauri/gen/schemas` — Tauri v2 Configuration Schemas

## Overview

The `src-tauri/gen/schemas` directory contains auto-generated JSON schema definitions generated by Tauri v2. These schemas provide validation, autocomplete, and type-checking in editors for Tauri configuration files and security capabilities.

---

## File Manifest

| File | Purpose |
|---|---|
| [`acl-manifests.json`](acl-manifests.json) | JSON schema defining valid Access Control List (ACL) permission manifest structures. |
| [`capabilities.json`](capabilities.json) | JSON schema validating window capability declarations in `src-tauri/capabilities/default.json`. |
| [`desktop-schema.json`](desktop-schema.json) | Complete JSON schema for desktop application configuration within `tauri.conf.json`. |
| [`macOS-schema.json`](macOS-schema.json) | JSON schema for macOS-specific bundle attributes (entitlements, frameworks, dmg settings). |
