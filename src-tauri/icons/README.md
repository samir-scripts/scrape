# `src-tauri/icons` — Application & System Tray Icon Assets

## Overview

The `src-tauri/icons` directory contains application icons and tray visual assets across multiple platform formats.

---

## File Manifest

| File | Target Platform & Resolution | Description |
|---|---|---|
| [`32x32.png`](32x32.png) | Linux / System Tray (32x32) | Low-resolution icon for standard-DPI taskbars and system trays. |
| [`128x128.png`](128x128.png) | Standard Desktop Icon (128x128) | Application bundle icon for standard desktop displays. |
| [`128x128@2x.png`](128x128@2x.png) | High-DPI Desktop Icon (256x256) | Retina / high-DPI application icon. |
| [`icon.icns`](icon.icns) | macOS Application Bundle | Multi-resolution Apple icon resource containing 16x16 through 1024x1024 resolutions for macOS Finder and Dock. |
| [`icon.ico`](icon.ico) | Windows Executable & Taskbar | Multi-layer Windows icon resource embedded into the executable binary and displayed in the Windows taskbar. |
